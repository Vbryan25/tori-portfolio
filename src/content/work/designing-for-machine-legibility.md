## The observation

Every interface I ship now is consumed by two audiences: humans and AI agents. Humans read the layout. Agents read the DOM.

## What this changes

Ambiguous labels break agents but not humans. Custom cursors and hover-only affordances are invisible to agents. Design systems get more useful the more explicitly named their tokens are.

## What I'm doing about it

I audit my own interfaces with agents. I write labels that pull double duty. I treat the DOM as a design surface, not an implementation detail.
